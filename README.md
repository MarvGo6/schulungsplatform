# Schulungsplatform

Lokaler Prototyp einer internen Schulungsplattform fuer Teams.

## Funktionen

- Login mit Admin- und Nutzerrolle
- Adminbereich fuer Kursverwaltung, Teamzugang und Reporting
- Nutzerbereich zeigt nur zugewiesene, veroeffentlichte Kurse
- Dashboard mit Kursen, Lernenden, Durchschnittsfortschritt und Zertifikatszaehler
- Kursbibliothek mit Filter fuer veroeffentlichte Kurse und Entwuerfe
- Course Builder fuer Titel, Beschreibung, Kategorie, Lektionen und Quizfrage
- Teamverwaltung mit Login-Erstellung und Einschreibung in veroeffentlichte Kurse
- Reporting fuer Fortschritt und Abschlussstatus

## Demo-Login

- Admin: `admin@team.local` / `admin123`
- Nutzer: `anna@team.local` / `lernen123`

## Lokal starten

Oeffne `index.html` direkt im Browser.

## Deployment

Die App ist eine statische Website und kann ohne Build-Schritt bei Vercel deployt werden.
